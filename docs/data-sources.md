# データソース

「日本では空気と水はどれだけきれいになったか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-06。軸は e-Stat API のメタ取得・実測値で確認済み。

## 1. 結論

空気・水の「きれいさ」を、**下水道等の普及**と**公害苦情（大気・水質）**の長期変化で見せる。
環境基準達成率そのものの長期DBは e-Stat に無く、第1版は一次ソースとして取得できる系列に限定する。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | SSDS Ｈ居住 + Ｋ安全 + 公害苦情調査 | `0000010208` / `0000010111` / `0003293269` | 指標×年 | 下水道・水洗化・苦情件数 |
| 大気水質 | 公害苦情調査（種類別推移） | `0003293269` | 種類×年 | 件数・構成比 |
| 地域 | SSDS Ｈ居住 + Ｋ安全 | `0000010208` / `0000010211` | 指標×年×都道府県 | 普及率・人口当たり苦情 |

出典表記: 公害等調整委員会「公害苦情調査」、下水道関連は社会・人口統計体系経由（e-Stat）。原系列の下水道は国土交通省等、苦情は公害苦情調査。

## 2. 採用データセット（メタ・実測）

### `0000010208` — 都道府県データ 社会生活統計指標 Ｈ　居住

- 採用:
  - `#H05304` 下水道普及率（〜2011）
  - `#H0530401` 下水道普及率（2012〜）。全国値は 2016〜2021。2012–2015 は都道府県のみ
  - `#H05306` 水洗化人口比率（1975–2021、一部欠年）
  - `#H05307` 汚水処理人口普及率 / `#H05308` 下水道処理人口普及率（収録は直近のみ。参考）
- 実測（全国）: `#H05304` 1975年 22.8% → 2011年 74.4%。`#H0530401` 2021年 80.5%

### `0000010111` — 都道府県データ 基礎データ Ｋ　安全

- 採用: `K6101` 公害苦情取扱件数 / `K6103` 典型7公害受付件数
- 種類別 `K610301`（大気）・`K610302`（水質）等は **1975–2007** まで。以降は収録なし
- 実測（全国）: 1975年 取扱 94,654件 → 2023年 74,608件

### `0000010211` — 都道府県データ 社会生活統計指標 Ｋ　安全

- 採用: `#K09201` 公害苦情受付件数（人口10万人当たり）1975–2023
- 実測（全国）: 1975年 60.1 → 2023年 39.4

### `0003293269` — 公害苦情調査 公害の種類別苦情件数の推移

- 軸: 表章(件数/構成比) × 公害の種類(12) × 年度(1972–2016)
- 採用種類: 大気汚染 `190` / 水質汚濁 `200` / 騒音 `230` / 振動 `290` / 悪臭 `310` / 土壌 `210` / 地盤沈下 `300` / 典型7計 `180` / 合計 `100`
- 実測突合: 大気・水質は SSDS `K610301` / `K610302` と 1975–2007 で一致
- 実測: 水質汚濁 1972年 14,197件 → 2016年 6,442件

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| 環境基準達成率（NO2・SPM・Ox・BOD 等） | e-Stat DB に長期時系列が無い。環境省報道発表・環境展望台は第2版 |
| SSDS Ｂ自然環境（`0000010102`） | 面積・気象が中心で、大気・水質の「きれいさ」物語に不向き |
| 大気汚染物質排出量総合調査 | 3年周期・施設排出が主。苦情・普及の物語と軸が違う |
| 公害苦情調査の 2017年以降種類別 | e-Stat DB の推移表が 2016 で停止。総数のみ SSDS で延長 |
| 2012–2015 の全国下水道普及率 | `#H0530401` に全国セルが無い。都道府県平均で埋めない |

## 4. 接続・定義ルール

- **下水道普及率**は定義改定あり。`#H05304`（〜2011）と `#H0530401`（2012〜）を別系列として扱い、UI で断絶を注記する。全国の 2012–2015 は `null`
- **公害苦情**は行政が受け付けた件数。環境濃度そのものではない
- 大気水質ビューの構成比は、各年の「合計」(`100`) を分母
- 地域の相対色は **県値 / 全国値**
- 表示年は調査年コードの西暦部分（SSDS・公害苦情とも `YYYY100000`＝年度）

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × year | cases / rate | metrics |
| `kind.json` | code × year | cases / share | codes |
| `geo.json` | metric × year × area | value / relative | metrics, areas |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。

## 6. 注記（UIに短く出す）

- 下水道普及は生活排水処理のインフラ整備。水質そのものの測定値ではない
- 公害苦情の減少は、規制・意識・定義変更の複合。濃度改善の直接指標ではない
- 大気汚染苦情は 2000 年前後にピーク（ディーゼル規制前後）
- 種類別の苦情件数は 2016 年度まで。以降は総数のみ
